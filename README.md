# Dunia Bandingan Semacam: Kembara Misi Emosi

Interactive Bahasa Melayu Year 3 site for learning *bandingan semacam* (similes), with an emotion-character theme. It has notes, four game stations, badges, a PDF certificate and a camera selfie frame.

**Tech:** TanStack Start (React 19), Tailwind CSS 4, jsPDF, Web Audio, getUserMedia/canvas. Deployed on Netlify.

**Run locally:** `pnpm install` then `netlify dev --port 8889` (or `pnpm dev`).

**Roadmap:** more questions per station, teacher dashboard, device QA for the camera on iOS.
